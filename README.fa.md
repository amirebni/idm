# MyDM

فارسی | [English](README.md)

یک دانلود منیجر شخصی شبیه IDM برای ویندوز (پایتون + tkinter) همراه با افزونهٔ کروم/اج.
صفحهٔ پروژه: https://github.com/amirebni/idm

## امکانات

**دانلود**
- دانلود چندبخشی (۱ تا ۳۲ بخش) با قابلیت ادامه (Resume)، فایل `.part` و محدودکنندهٔ سرعت
- صف دانلود همزمان، تلاش مجدد و «Download again»
- **Change link...** برای دانلود نیمه‌کاره: لینک‌ها منقضی می‌شوند؛ لینک جدید را بگذار و دانلود از همان جا ادامه پیدا می‌کند
- دسته‌بندی (فشرده، سند، موزیک، برنامه، ویدیو) با پوشهٔ جدا برای هر دسته (اختیاری)
- پروکسی: سیستمی (خودکار)، بدون پروکسی یا دستی (http / socks5)
- زمان‌بند: شروع/توقف در ساعت دلخواه، و خاموش کردن / Sleep / Hibernate / بستن برنامه بعد از پایان دانلودها

**ویدیو و استریم**
- یوتیوب، آپارات، ورزش۳ و سایت‌های دیگر از طریق yt-dlp با انتخاب کیفیت و حجم تقریبی (با علامت `≈`)
- استریم‌های HLS و DASH با ffmpeg
- خطای «Sign in to confirm you're not a bot» یوتیوب: افزونه کوکی ورود شما را می‌فرستد، یا از cookies.txt / کوکی‌های Firefox استفاده کن
- پنجرهٔ «Download now» یا «Add to list»، گزینهٔ اجبار IPv4

**افزودن لینک**
- Add URL، چند لینک همزمان (پنجرهٔ دسته‌ای)، ورود/خروج فهرست لینک‌ها (متنی)
- کشیدن و رها کردن لینک از مرورگر
- پایش کلیپ‌بورد: اول بپرس (پیش‌فرض) یا خودکار اضافه کن

**افزونهٔ مرورگر (کروم / اج، Manifest V3)**
- نوار دانلود روی ویدیو/صدای در حال پخش
- راست‌کلیک «Download with MyDM» روی لینک و روی متن انتخاب‌شده (همهٔ لینک‌های داخل متن)
- ارسال referer، کوکی و user agent به برنامه

**رابط کاربری**
- جدول دانلودها: منو، نوار ابزار، جستجو، سایدبار دسته‌ها و صف، نوار وضعیت
- تم روشن / تیره / سیستم، ردیف‌های فشرده یا راحت
- تغییر اندازهٔ پنجره‌ها، ستون‌ها (کشیدن لبهٔ سرستون) و سایدبار (کشیدن نوار بین سایدبار و لیست)؛ اندازه‌ها یادآوری می‌شوند؛ View > Reset layout
- تب‌های تنظیمات: General، Connection، Browser، Video، About
- تب About: نسخه، توضیح کوتاه، لینک گیت‌هاب و دکمهٔ **Check for updates**

## اجرا از سورس
```sh
pip install "requests[socks]" tkinterdnd2
python dm.py
```
برای سایت‌های ویدیویی فایل‌های `yt-dlp`، `ffmpeg.exe` و `qjs.exe` را کنار `dm.py` بگذار (نصب‌کننده خودش این کار را می‌کند).

## ساخت فایل نصبی ویندوز
۱. پروژه را روی گیت‌هاب Push کن. فایل `.github/workflows/build.yml` با PyInstaller و Inno Setup نصبی را می‌سازد و دو Artifact می‌گذارد: `MyDM-Setup-vX` و `MyDM-Extension-vX` (هر هفته هم خودکار اجرا می‌شود تا yt-dlp جدید را بگیرد).
۲. برای انتشار Release (که **Check for updates** از آن می‌خواند) یک تگ بزن:
   ```sh
   git tag v3.0
   git push origin v3.0
   ```
   Workflow نصبی و `MyDM_Extension.zip` را به Release گیت‌هاب اضافه می‌کند.

## نصب افزونه
در `chrome://extensions` حالت Developer mode را روشن کن، **Load unpacked** را بزن و پوشهٔ `extension` را انتخاب کن (نصب‌کننده آن را کنار برنامه کپی می‌کند و در Settings > Browser دکمه‌ای برای باز کردنش هست). بعد از هر به‌روزرسانی روی افزونه Reload بزن.

## داده‌ها و تنظیمات
همه‌چیز در `%USERPROFILE%\.mydm` ذخیره می‌شود (`state.json`، کوکی‌ها، آپدیت‌های yt-dlp). با متغیر `MYDM_HOME` می‌شود پوشه را عوض کرد. برنامه فقط روی `127.0.0.1` (پورت‌های ۱۷۸۹۰ تا ۱۷۸۹۹) برای افزونه گوش می‌دهد.

## رفع اشکال
- **یوتیوب درخواست ورود می‌کند**: در کروم با افزونهٔ نصب‌شده وارد یوتیوب شو و دوباره امتحان کن. یا در Settings > Video یک cookies.txt بده.
- **Video engine لود نشده**: Settings > Video > Update video engine.
- **افزونه می‌گوید برنامه اجرا نیست**: MyDM را باز کن و گزینهٔ «Accept downloads from the browser extension» روشن باشد.
